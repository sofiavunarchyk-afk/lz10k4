## Хід роботи

Роботу виконано в середовищі Visual Studio як проєкт Windows Forms (C++/CLI). Для двох завдань на формі використано елемент керування `TabControl` з двома вкладками, на кожній з яких розміщено окрему реалізацію завдання. Для зберігання даних використано контейнер `std::forward_list`, для підключення якого на початку файлу `MyForm.h` додано:

```cpp
#include <forward_list>
#include <iterator>
```

Оскільки клас форми є керованим (`ref class`), список оголошується не полем класу, а безпосередньо всередині обробників натискання кнопок.

### Завдання А. Видалення елемента перед кожним числом 55

**Алгоритм:**

1. Створюється список дійсних чисел `{ 12.5, 55.0, 8.3, 99.1, 55.0, 4.0 }`, який виводиться у перший `ListBox`.
2. Використовуються два ітератори: `prev` (стоїть перед поточним елементом, ініціалізується через `before_begin()`) і `curr` (поточний елемент).
3. На кожному кроці за допомогою `std::next(curr)` переглядається наступний елемент. Якщо він дорівнює 55.0, то поточний елемент видаляється методом `erase_after(prev)`.
4. В іншому випадку ітератори зсуваються вперед.
5. Результуючий список виводиться у другий `ListBox`.

**Код:**

```cpp
private: System::Void button1_Click(System::Object^ sender, System::EventArgs^ e) {
    std::forward_list<double> list = { 12.5, 55.0, 8.3, 99.1, 55.0, 4.0 };

    listBox1->Items->Clear();
    for (double x : list) {
        listBox1->Items->Add(x.ToString());
    }

    auto prev = list.before_begin();
    auto curr = list.begin();

    while (curr != list.end()) {
        auto nextIt = std::next(curr);                 // дивимось на наступний елемент
        if (nextIt != list.end() && *nextIt == 55.0) {
            // curr стоїть перед 55.0, тому видаляємо його
            curr = list.erase_after(prev);
        }
        else {
            prev = curr;
            ++curr;
        }
    }

    listBox2->Items->Clear();
    for (double x : list) {
        listBox2->Items->Add(x.ToString());
    }
}
```

**Результат виконання:**

| Початковий список | Список після видалення |
|---|---|
| 12.5, 55, 8.3, 99.1, 55, 4 | 55, 8.3, 55, 4 |

### Завдання Б. Оцінки студентів

**Алгоритм:**

1. Створюється список оцінок `{ 10, 8, 12, 9, 7 }`, який виводиться у перший `ListBox`.
2. Дві нові оцінки зчитуються з текстових полів `TextBox` методом `Convert::ToInt32()`. Для коректної обробки неправильного введення використано `try...catch`.
3. Обидві оцінки додаються на початок списку методом `push_front()`, після чого список виводиться у другий `ListBox`.
4. Перша оцінка видаляється методом `pop_front()`, оновлений список виводиться у третій `ListBox`.
5. Оскільки в `std::forward_list` немає методу `size()`, сума й кількість елементів обчислюються вручну в циклі, після чого знаходиться середній бал як `sum / count`.

**Код:**

```cpp
private: System::Void button2_Click(System::Object^ sender, System::EventArgs^ e) {
    std::forward_list<int> grades = { 10, 8, 12, 9, 7 };

    // 1. Початковий список
    listBox3->Items->Clear();
    for (int x : grades) {
        listBox3->Items->Add(x.ToString());
    }

    // 2. Зчитуємо дві оцінки з TextBox
    int g1, g2;
    try {
        g1 = Convert::ToInt32(textBox1->Text);
        g2 = Convert::ToInt32(textBox2->Text);
    }
    catch (System::Exception^) {
        MessageBox::Show("Введіть цілі числа в обидва поля!");
        return;
    }

    // 3. Додаємо 2 оцінки на початок
    grades.push_front(g1);
    grades.push_front(g2);

    listBox4->Items->Clear();
    for (int x : grades) {
        listBox4->Items->Add(x.ToString());
    }

    // 4. Видаляємо першу оцінку
    grades.pop_front();

    // 5. Виводимо список і рахуємо суму та кількість
    int sum = 0, count = 0;
    listBox5->Items->Clear();
    for (int x : grades) {
        listBox5->Items->Add(x.ToString());
        sum += x;
        count++;
    }

    // 6. Середній бал
    if (count > 0) {
        double avg = (double)sum / count;
        label8->Text = "Середній бал: " + avg.ToString("F2");
    }
    else {
        label8->Text = "Список порожній";
    }
}
```

**Результат виконання** (нові оцінки: 11 і 9):

| Етап | Список |
|---|---|
| Початковий | 10, 8, 12, 9, 7 |
| Після додавання двох оцінок | 9, 11, 10, 8, 12, 9, 7 |
| Після видалення першої | 11, 10, 8, 12, 9, 7 |

Середній бал: (11 + 10 + 8 + 12 + 9 + 7) / 6 = 57 / 6 = **9.50**

## Висновок

У ході лабораторної роботи я опанувала роботу з однозв'язними списками за допомогою контейнера `std::forward_list` у середовищі Visual Studio (C++/CLI Windows Forms). Було розглянуто особливості цього контейнера: доступ до елементів лише послідовно в одному напрямку, відсутність методу `size()` та операції вставки й видалення після вказаного ітератора (`insert_after`, `erase_after`) з використанням `before_begin()`.

У завданні А реалізовано видалення елемента перед кожним числом 55 за допомогою двох ітераторів (`prev` і `curr`) та методу `erase_after()`. У завданні Б застосовано методи `push_front()` і `pop_front()` для додавання та видалення елементів на початку списку, а також обчислено середній бал вручну, оскільки кількість елементів не зберігається в контейнері. Результати виводилися у компоненти `ListBox` та `Label`, для вибору між завданнями використано `TabControl`. Усі програми працюють коректно на тестових даних.
